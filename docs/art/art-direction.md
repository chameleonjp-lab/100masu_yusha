# 100マス勇者　絵と演出の指示書

この文書は、画面を作る担当（screen-implementation）が**そのまま従える**ように、絵の調子・色・文字・形・動き・音・素材をまとめたもの。数字は402px幅の画面を基準にした CSS px。秒は「標準」の値で、「短縮」「動きを控える」の値は第6章の表にある。

- 正本: [要件仕様書](../requirements.md)（C01・R41〜R47・S01〜S11）、[開発の約束](../dev/contract.md)、[冒険コンテンツ](../../data/adventure-content.json)、[balance-draft-2](../../data/balance-draft-2.json)
- 見本: `docs/art/mockups/*.svg`。**見本は方向を示すための手描きSVGで、最終素材ではない**（右上にピンクの「見本」札がある）。この担当が一から描いたものなので、図形を素材づくりの元にしてよい。他者の絵・フォント・音源は使っていない。
- 見本の作り方: `docs/art/mockups/src/`（Python。図形の部品と姿勢を組み合わせてSVGを書き出す。`python3 shot.py <svg> <png>` は確認用の撮影）。
- 画像生成の道具は、この作業環境では使えなかった。見本はすべて手で座標を決めたSVGで、ヘッドレスChromeで描画して目で確かめた。
- 見本の中のピンクの丸数字（①②…）は説明用の印で、画面には出さない。

## 0. いちばん大事な約束（7つ）

1. **黄色い木札＝自分の操作。紙の札＝敵の予告。** 押せるボタンは必ず黄色（`--act`）か木色（`--wood`）の「厚みのある木札」。敵の次の行動は必ず「ひもで下がった紙の札」。材質・形・置き場所（下＝自分、上＝敵）で分ける。
2. **予告は形＋言葉＋絵記号で読める。色と音は補助。** 白黒にしても、音を消しても、4種類（攻撃・大技・守り・すき）を見分けられること。
3. **敵の体の形（シルエット）も予告どおりに変わる。** 大技はいちばん大きく形が変わる構え。札を読まなくても体で分かる。
4. **キャラクターは切り抜きシール。** 濃い輪郭（3px）の外側に、クリーム色のふち（3px）を必ず付ける。明るい背景でも暗い背景でも形が抜ける。
5. **影はぼかさない。** 紙を重ねたような「ずらした固い影」だけを使う（iPhone Safariで軽い）。
6. **味方は人の形＋黄色いスカーフ、敵は生き物・石・鉄の形。** 黄色は「自分たち」の色。敵の配色に `--act` の黄色を使わない。
7. **結果の文字は消えない。** 標準・短縮・動きを控える・消音のどの組み合わせでも、確定した数値と次の操作が画面に残る。

## 1. 世界と調子

### 1.1 出発点と、一日の旅

出発点は「少し愉快な旅の絵本風」（C01）。子どもが一人で読めて、敵も仲間も輪郭で見分けられ、技の意味を短い言葉で示す。

旅は**一日の物語**として色を付ける。朝に四つ辻の門を出て、昼に水辺、午後に鉱山、夕方に霧の森を抜け、日が沈むころ城下に着き、夜の城門で鐘が一度鳴る。区間ごとに空の色が進むので、どこまで来たかが色でも分かる（色だけには頼らない。区間名と番号を必ず出す）。

### 1.2 比べた二つの案

同じ二画面（戦闘：敵が大技を構えた手／盤面：次の6マス）で、二つの案を描いて比べた。

| | A案「切り絵の紙しばい」 | B案「水彩の旅日記」 |
|---|---|---|
| 見本 | `mockups/option-a-battle.svg` / `mockups/option-a-board.svg` | `mockups/option-b-battle.svg` / `mockups/option-b-board.svg` |
| 絵の作り | 平らな色紙を重ねた切り絵。濃い茶の輪郭3px、クリーム色の切り抜きふち、ずらした固い影 | 水彩のにじみと鉛筆の細い線（1.25px）。淡い色、手書き風のメモ |
| 敵の予告 | ひもで下がる紙の札。種類ごとに札の形が違う（大技はぎざぎざ）。一行の足元に「危ない影」 | 敵のまわりの色の光（赤くにじむ）と、付せん風のメモ「つぎは大技」 |
| 自分の操作 | 画面下の黄色い木札（厚み4px）。札と材質が違う | 淡い水彩のまるいボタン。メモと材質が近い |
| 盤面の次の6マス | 道の上の色紙のマス＋下の帯にサイコロの目と種類名 | 点線の小道の上の丸いスタンプ＋手書き風の名前 |

### 1.3 比べ方と結果

| 確かめたこと | やり方 | A案 | B案 |
|---|---|---|---|
| 白黒でも予告が読めるか | 見本を白黒にして見る | 札の形（ぎざぎざ／盾形／丸）と「!!」、足元の斜線の影で読める | 赤い光が灰色になり、ほかの手と区別できない。メモの文字だけが頼り |
| 小さくしても読めるか | 見本を4分の1に縮める | 札のぎざぎざと敵の頭上の腕が残る | 細い線とにじみが消え、敵の形がぼやける |
| 予告と自分の操作を取り違えないか | 画面の上下で材質を比べる | 上＝紙の札、下＝厚みのある黄色い木札。形も材質も違う | 予告のメモもボタンも淡い紙色で、目が迷う |
| 文字の読みやすさ | 文字と地の明るさの比（WCAG） | 本文 14.05:1、黄色い札の上の文字 9.16:1 | 淡い地の上の細い文字で 4.5:1 前後まで下がる |
| 4つの道の色との相性 | 正本の道の色（`routes[].color`）を置く | 濃い輪郭と色紙の上で落ち着く | 4色とも暗めなので、水彩の淡さの中で浮く |
| iPhone Safari の負荷 | 使う効果を数える | 単色の塗りと固い影だけ。フィルターは背景の紙目の小さなタイル1枚 | にじみに `feTurbulence`＋`feDisplacementMap` を全面に使う必要があり、動かすと重い |

**A案「切り絵の紙しばい」を採用する。** 理由は三つ。

1. **予告が形で読める。** 札の形・敵の構え・足元の影の三つが、色と音なしでも同じことを言う。B案は色の光に頼るため、白黒や色の見え方が違う人には弱い。
2. **予告と次の操作がはっきり分かれる。** 敵の予告は上半分の「紙の札」、自分の操作は下半分の「黄色い木札」。B案は両方が淡い紙で、目が迷う。
3. **軽い。** 平らな塗りと固い影は、iPhone Safariで動かしても軽い。B案のにじみは全面フィルターが必要。

B案の淡いにじみは採らない。遠景の空は単純な縦のグラデーション（A案の一部）で十分に奥行きが出る。

> 道の色について分かったこと: 正本の4色（#976021・#804e49・#4c6350・#46677f）は**明るさがほぼ同じ**（互いのコントラスト比 1.03〜1.29）。白黒や色の見え方によっては区別できない。だから道は、色に加えて**道標の形・模様・道の地面と道ばたの小物**で見分ける（第3章）。

## 2. 色・文字・線・紙

### 2.1 色の名前（CSSの変数）

`src/style.css` の先頭にそのまま置く。画面の部品はこの名前だけを使い、色コードを直接書かない。

```css

  --paper-card: #FFF9EC;   /* カード・札の地 */
  --paper-deep: #EBDDBF;   /* くぼみ・ゲージの溝 */
  --cut: #FFFBF2;          /* キャラクターの切り抜きふち */
  --ink: #2A1E16;          /* 輪郭と本文 */
  --ink-2: #5A4636;        /* 補足の文字 */
  --ink-3: #7A6553;        /* 使えない操作の文字（理由の文と一緒に使う） */
  --text: var(--ink);      /* 文字色（夕暮れでは明るくなる） */
  --text-2: var(--ink-2);
  --line: var(--ink);      /* UIの枠線（夕暮れでは暗い紫） */
  --shadow: rgba(42,30,22,.22);   /* 固い影（ぼかさない） */

  /* 自分の操作（木札） */
  --act: #F4B942;  --act-press: #DE9C26;  --act-edge: #9A6416;  --act-ink: #2A1E16;
```

### 2.3 文字

- 書体は端末にあるものだけを使う（読み込みなし・権利の心配なし）:
  `font-family: "Hiragino Maru Gothic ProN", "Hiragino Sans", "BIZ UDPGothic", "Yu Gothic UI", "Noto Sans JP", system-ui, sans-serif;`
- 数字はすべて `font-variant-numeric: tabular-nums;`（数えるときに幅が揺れない）。
- 本文の行間 1.6、見出し 1.3、数字だけの行 1.0。

| 名前 | 大きさ | 太さ | 使いどころ | 最小 |
|---|---:|---|---|---|
| `--fs-cap` | 13px | 700 | 全体地図の番号、カードの小見出し、サイコロの目の脇の言葉 | **これより小さい文字は作らない** |
| `--fs-small` | 14px | 700 | 札の中の数字ラベル（攻撃 46）、ボタンの下の小さな説明 | |
| `--fs-body` | 16px | 400 | 出来事の文、予告の文、結果の文、説明 | 文章は必ず16px以上 |
| `--fs-label` | 17px | 800 | 副ボタンの言葉 | |
| `--fs-button` | 20px | 800 | 主ボタン（サイコロを振る・攻撃・買う） | |
| `--fs-title` | 20px | 800 | 行動名（石腕の大振り）、カードの題 | |
| `--fs-num` | 20px | 800 | 体力・魔力・所持金の数字 | |
| `--fs-num-l` | 28〜32px | 800 | 売店の所持金と差額、装備の比べ（9 → 11） | |
| `--fs-pop` | 36〜40px | 900 | 飛び出す数字（命中・受けた量） | |
| `--fs-die` | 56px | 900 | サイコロの目 | |
| `--fs-hero` | 30px | 900 | 結果の見出し（魔王をたおした！） | |

- 文字を絵の上に直接置かない。必ず `--paper-card` の札か帯の上に置く（例外は飛び出す数字。白文字＋墨のふち4px、`paint-order: stroke`）。
- 文字拡大（Safariの表示の拡大・縮小）で長くなったら折り返す。札とカードは高さを伸ばし、ボタンは縮めない。
- ふりがなは初版では付けない（課題に残す）。代わりに、言葉は短く、必ず絵記号と並べる。

### 2.5 顔の決まり（全部の敵で同じ）

予告の種類ごとに、**全部の敵が同じ顔**をする。子どもは5つの顔を一度覚えれば、どの敵でも読める。

| 顔 | 目 | 眉 | 口 | 付けるもの | 使う手 |
|---|---|---|---|---|---|
| ふだん | 黒い丸＋白い光 | なし | 小さな笑み | — | 待機 |
| にらむ | 黒い丸＋白い光 | つり眉（短い線） | 「へ」の字 | — | 通常攻撃 |
| ためる | 半分閉じた黒目（下半分の半円） | 太いつり眉 | 歯の見える四角い口 | 頭の上に赤い力の線3本 | 大技 |
| とじる | 閉じた目（下向きの弧） | なし | 一文字 | — | 守り |
| へとへと | 白い丸に小さな黒目（下を見る） | なし | 開いた口と舌 | 青い汗のしずく | 反撃の隙 |
| いたい | 「＞＜」 | なし | 波線 | — | 攻撃を受けた瞬間だけ |

勇者と仲間は、待機は「ふだん」、攻撃・防御・呪文では「にらむ」（きりっとした顔）、受けたときは「いたい」。

### 2.6 紙と材質の作り方（軽く作る）

| 表現 | 作り方 | 禁止 |
|---|---|---|
| 紙の地の目 | `assets/img/tex/paper.svg`（160×160のタイル。`feTurbulence type="fractalNoise" baseFrequency=".9" numOctaves="2" stitchTiles="stitch"` → `feColorMatrix` で茶色の点を不透明度6%）を `background-image` で敷き詰める。画像として一度だけ描かれるので軽い。読めなければ無地でよい | 画面に直接置いたSVGへ `feTurbulence` を掛けること |
| 紙を重ねた影 | `box-shadow: 0 3px 0 var(--shadow)`（ぼかし0）。SVGでは同じ形を3px下にずらして `--shadow` で塗る | `filter: drop-shadow()`、ぼかしのある影、動く物への影 |
| 切り抜きふち | 4.1の「二回描き」 | フィルターで作るふち |
| 木札の厚み | 同じ形を4px下に `--act-edge` で描き、上の面に白い細線（不透明度55%）で光 | 立体のグラデーション |
| 道の模様 | 第3章の4つの模様。小さなSVGタイルを `background-image` で | — |
| 危ない影（大技） | 斜線の模様（45°、3px幅、不透明度75%の紅）＋点線の縁の楕円 | 赤い光のにじみ |
| 霧（第4区間） | 不透明度0.5〜0.7の白い平らな帯を2〜3枚、遠景と中景の間にはさむ | ぼかし |

動かす物には `transform` と `opacity` だけを使う（`will-change: transform` は動いている間だけ付ける）。`filter`・`box-shadow`・`clip-path` を動かさない。

## 3. 4つの道と5つの区間

### 3.1 4つの道は「色＋道標＋模様＋地面」で見分ける

正本の4色は明るさがほぼ同じなので、色だけで区別させない。どの画面でも、道は下の4つを全部そろえて出す。見本: `mockups/sheet-routes-bands.svg`。

## 4. キャラクター

見本: `mockups/sheet-characters.svg`（勇者4職と仲間4人）、`mockups/sheet-enemies.svg`（通常の敵13種の待機と代表の構え）、`mockups/sheet-bosses.svg`（強敵3種と魔王の前半・王冠・後半）、`mockups/sheet-telegraph.svg`（予告の4種類の札・顔・足元の影）。

### 4.1 作り方（全員共通）

1. **1キャラクター＝1ファイル**（`assets/img/chars/*.svg`・`assets/img/enemies/*.svg`）。`viewBox` は下の大きさ、`overflow="visible"`（構えで剣や腕が枠の外に出てよい）。
2. **部品は `<g data-part="名前">`**。名前は小文字とハイフン（`body`・`head`・`arm-front`・`weapon`・`face-big` など。各キャラクターの表を参照）。同じ敵が同時に何体も出る（霧狼の分身）ので、画面に入れるときは `id` を使わず `data-part` で選ぶ。素材の中に `style=""` を書かない（色は `fill=`・`stroke=` の属性だけ）。
3. **二回描き（切り抜きふち）**: 読み込んだSVGの中身を同じ `<svg>` に2回入れる。下に `<g class="cut-pass">`、上に `<g class="main-pass">`。

   ```css
   .cut-pass * { fill: var(--cut); stroke: var(--cut); stroke-width: 9px; stroke-linejoin: round; stroke-linecap: round; }
   .cut-pass [fill="none"] { fill: none; }
   .cut-pass [data-part^="face-"] { display: none; }
   .boss .cut-pass * { stroke-width: 10px; }   /* 輪郭4pxの強敵・魔王 */
   ```
   姿勢の変形は `data-part` に掛けるので、2枚に同じ変形が掛かり、ふちは姿勢についてくる。
4. **姿勢＝根元の要素のクラス**: `.pose-idle` `.pose-attack` `.pose-big` `.pose-guard` `.pose-open` `.pose-hit`（勇者は `.pose-walk1` `.pose-walk2` `.pose-cast` `.pose-item` `.pose-victory` `.pose-down` も）。部品ごとの回転・移動は下の表の値をCSSに書く。

   ```css
   [data-part] { transform-box: view-box; transition: transform var(--pose-t, .3s) ease-out; }
   .EN05 [data-part="arm-front"] { transform-origin: 72px 104px; }
   .EN05.pose-big [data-part="arm-front"] { transform: rotate(150deg) scale(1.12); }
   [data-part^="face-"] { display: none; }
   .pose-big [data-part="face-big"] { display: inline; }
   ```
   `--pose-t` は標準 .3s、短縮 .12s、動きを控える 0s（代わりに全体を .15s で `opacity` 入れ替え）。
5. **姿勢にだけ出る部品**（泡・しっぽの輪・蓋・糸・足元の線など）は普段 `display:none`、その姿勢のクラスで出す。
6. **向き**: 敵は左向き（一行は左にいる）。勇者と仲間は右向き。左右反転（`scale(-1,1)`）で向きを変えない。
7. **表示の大きさ（縦画面）**: 盤面の勇者 72px高、戦闘の勇者 110px、仲間 92px、通常の敵 180px角、強敵 220px角、魔王 260px角。輪郭が表示で3px（強敵・魔王は4px）になるよう、素材の `viewBox` はこの表示の大きさに近く作る。
8. **まだ読み込めていないとき**: 枠の60%の楕円（`--paper-deep`、点線の縁 `--ink-3`）と名前を出す。予告の札・言葉・絵記号は絵がなくても全部出る。

### 4.2 予告の決まり（4種類）

予告は**札の形・絵記号・言葉・敵の体と顔・画面の追加**の5つで同じことを言う。色と音は補助。

| 種類（正本の kind） | 札の形 | 絵記号 | 札の言葉 | 札のひとこと（共通） | 敵の顔 | 敵の体 | 画面の追加 | 音（第7章） |
|---|---|---|---|---|---|---|---|---|
| 通常攻撃 | 角の丸い四角（角12px）、上に8pxの朱の帯 | 斜めのひと振り `t-attack` | 攻撃 | ふつうの攻撃が来る | にらむ | 武器や腕を前へ。中くらいの動き | なし | `tell.attack` |
| 大技 | **上下がぎざぎざ**（歯の高さ8px・間隔16px）、枠3px、地は紅、見出しは白抜き | **ぎざぎざの星に「!!」** `t-big` | 大技 | 強い一撃が来る。防御で軽くできる | ためる＋力の線 | **いちばん大きく形が変わる**（頭上に上げる・後ろへ隠す・大きく広げる・高い所へ上がる） | **一行の足元に危ない影**（紅の斜線の楕円＋点線の縁）。影はゆっくり脈打つ（1.2秒で 0.96⇄1.04倍） | `tell.big`（低い音、音楽を下げる） |

| 反撃の隙 | **左右に半円の切り欠きがある札**（切符形、角16px・切り欠き半径10px）、上に若草の帯 | 的 `t-open` | すき | 攻撃は来ない。攻めどき | へとへと＋汗 | 武器を下ろす・座る・低くなる・殻が開く | 敵の弱い所に小さな的の印（直径24px） | `tell.open` |

## 6. 動きと音の時間表

### 6.1 決まり

- **設定は3つとも別々**: 演出（標準／短縮。いつでも切り替えられ、次の段階から効く）、動きを控える（オン／オフ。初めは端末の設定に合わせる）、音（効果音の音量・音楽の音量・一括消音）。どの組み合わせでも、確定した数値・結果の文・次の操作が残る。
- **成立の音は、保存が成った後に1回だけ**: 画面は `dispatch` の `effects` を受け取り、状態の保存（IndexedDB）が成功してから成立の音（硬貨・購入・鞘・留め具・袋・回復・レベルアップ・転職・加入・勝利・鐘・自己ベストなど）を鳴らす。保存に失敗したら成立の音は鳴らさず、失敗の文を出す。
- **成立でない音**（ボタンを触る音・転がる音・コンパスの針・試着の布・候補を見る音）は押した時に鳴らしてよいが、成立の音に似せない。
- **二度鳴らさない**: 起きたことごとに鍵 `${runId}:${revision}:${index}` を作り、鳴らした鍵を覚えておく。再描画・再開・連打で同じ鍵を鳴らさない。読み直したときは起きたことを再生せず、最後の状態を音なしで描く（音楽は最初のタップで始める）。
- **飛ばす**: 演出の途中で舞台を押す（または小さな「▶▶」）と、最後の画面へ飛ぶ。数字と文はすべて出る。まだ鳴っていない飾りの音（転がる・足音・振る風の音）は捨てる。まだ鳴っていない成立の音は、大事な順に**2つまで**を0.12秒ずらして鳴らす。大事な順: 勝利・敗北 ＞ レベルアップ ＞ 王冠のひび ＞ 大技の低音 ＞ 盾 ＞ 斬撃・受けた ＞ 回復 ＞ 硬貨 ＞ 袋・鞘・留め具 ＞ そのほか。
- **演出の間の操作**: 次の操作のボタンは見えたまま薄く（押せない）。最後の画面で押せるようになる。舞台を押すと飛ばす。
- **画面が隠れたら**（`visibilitychange` で hidden）: 予定の音と動きを全部捨てる。戻ったら最後の状態を描き直す。音の再開は次のタップで。
- **音楽を下げる**: 大技の低音・鐘・王冠のひび・勝利と敗北の旋律の間は、音楽を0.15秒で −9dB（約0.35倍）に下げ、終わってから0.6秒で戻す。城に着く時は音楽を0にして、魔王戦が始まるまで戻さない。
- **動きを控える**: 8pxを超える移動・拡大・回転・はね・揺れ・奥行きの動きを、0.15秒以下のフェードに置き換える。読むための「間」（止まる・静けさ）は残す（静けさは動きではない）。
- **点滅の安全**: 画面全体を光らせない。白い光は敵の絵だけ（不透明度0.6・0.08秒）、1秒に3回まで。

下の表の秒は「標準／短縮」。「控える」は動きを控える設定での見せ方。音の名前は第7章。

### 6.5 数字の見せ方（R43：構え → 命中 → 増減）

- **防いだ量**: 盾の形の札（`--num-block`、白文字、盾の絵記号、**マイナスを付けない**）「ふせいだ 5」を、防いだ人（勇者・盾役）の頭の上に出す。軽くした順（防御 → 盾役 → 小さい出目 → 札）に1枚ずつ、標準は0.15ずつずらす。短縮は合計の1枚「ふせいだ 17」。
- **受けた量**: 体力ゲージの右に大きな「−7」（`--num-dmg`、28px 900）と「体力」の言葉。ゲージは0.4で縮み、失った分を0.6のあいだ薄い色で残す。
- **与えた量**: 敵の上に白い数字（墨のふち4px、36px 900）と星形。偽物には「にせもの！ 0」。
- **回復**: 緑の「+12」と葉の絵記号。
- 飛ぶ数字は0.8で消えるが、**結果の帯に文で残す**。例「石門番の 石腕の大振り。防御で 12、盾役が 5 ふせいだ。体力 −7（41 → 34）」。
- 受けた量が0なら「ふせいだ」の札だけ出し、結果の帯に「ダメージなし」。

## 7. 音の作り方（WebAudio だけで作る。音のファイルは使わない）

### 7.1 つなぎ方

- `AudioContext` は1つ。最初のタップで作り、`resume()` する。`navigator.audioSession` があれば `type = 'ambient'`（端末の消音スイッチに従い、ほかの音と混ざる）。設定に「消音スイッチがオンだと音は出ません」と書き、「音を試す」で確かめられるようにする。
- 道すじ: 効果音の束 `sfxGain`、音楽の束 `musicGain` → 全体 `masterGain` → `DynamicsCompressor`（threshold −10dB、ratio 4、attack 3ms、release 120ms）→ 出力。
- 初めの音量: 全体0.8、効果音0.8、音楽0.5（どれも0より大きい。R46）。設定の0〜10を0〜1にして保存。一括消音は `masterGain` を0にする（個別の値は残す）。
- 白い雑音は1秒分の `AudioBuffer` を最初に1回だけ作り、使い回す。
- 音楽は先読みの予約（25msごとに、100ms先まで予約）で鳴らす。画面が隠れたら予約を止める。

### 7.2 レシピの読み方

各音は「声」の並び。1つの声＝1つの発振器（または雑音）＋音量の山。

| 記号 | 意味 |
|---|---|
| `t` | 鳴り始め（ms。音の頭からの時間） |
| `o` | `sine` `triangle` `square` `sawtooth` または `noise`（白い雑音＋ `BiquadFilter`） |
| `f` | 周波数Hz（雑音ではフィルターの中心）。`f2` があれば `g` ms で指数的に `f2` へ動かす |
| `ft` `q` | 雑音のフィルターの種類（`bandpass` `lowpass` `highpass`）と Q |
| `lp` | 発振器の後ろに置く `lowpass` の周波数（省略＝なし） |
| `a` `h` `d` | 音量の山: 0.0001 から `a` ms で `v` へ直線 → `h` ms そのまま → `d` ms で 0.0001 へ指数で下がる |
| `v` | 山の高さ（効果音の束に入る前の音量） |
| `det` `pan` | ずらし（セント）、左右（−1〜1） |

### 7.5 3つの曲（短く繰り返すスケッチ）

表記: 1小節＝8分音符8つ。`-` は休み、`~` は前の音をのばす。音名は A4=440Hz（`f = 440 * 2 ** ((midi-69)/12)`）。

**街道**（ト長調・100BPM・8小節。区間ごとにテンポだけ 104／100／96／88／108。第4区間は旋律に lowpass 1800 を足し、第5区間は2・4拍に小太鼓を足す）

- 旋律（triangle、a5 d220 v0.10。1オクターブ下の sine v0.03 を重ねる）

```text
1| G4 -  B4 -  D5 -  B4 -  |2| C5 -  A4 -  G4 ~  ~  -  |3| E4 -  G4 -  A4 -  B4 -  |4| A4 ~  ~  -  -  -  D4 -  |
5| G4 -  B4 -  D5 -  E5 -  |6| D5 -  B4 -  A4 ~  G4 -  |7| E4 -  G4 -  A4 -  B4 A4 |8| G4 ~  ~  ~  -  -  -  -  |
```
- 低音（sine、四分音符、a5 d300 v0.14）: `G2 D3 G2 D3 | C3 G2 C3 G2 | E2 B2 E2 B2 | D2 A2 D2 A2 | G2 D3 G2 D3 | C3 G2 D3 D2 | C3 G2 D3 A2 | G2 D3 G2 -`
- 木の打楽器: 2拍目と4拍目に「カッ」（noise bandpass 2500 q3 a1 d20 v0.06）、1拍目に小さな「トン」（sine 90 a2 d60 v0.10）。

**通常戦**（イ短調・140BPM・4小節を2回。2回目は旋律の1〜2小節を1オクターブ上）

```text
低音 (square, lowpass 800, a5 d140 v0.08)
1| A2 A2 E3 A2 A2 E3 A2 G2 |2| F2 F2 C3 F2 F2 C3 F2 E2 |3| D2 D2 A2 D2 D2 A2 D2 E2 |4| E2 E2 B2 E2 G#2 G#2 B2 E2 |

```

