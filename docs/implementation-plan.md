# 100マス勇者　実装計画書

1番の門で道を一本選び、五つの宿場を経て、100番の魔王を倒すところまでを、まず端末内で遊べるようにする。[要件仕様書](./requirements.md) の R01〜R50・C01〜C05・S01〜S11 を、以下の T01〜T09 に分けて実装する。ゲームの内容と数値は[冒険コンテンツデータ（形式2.0）](../data/adventure-content.json)を正本とする。

以下は**これから作るゲームと、完成を確かめる手順**。データがそろっていても、各マスの操作や戦闘が遊べること、目標時間で終わることを示すものではない。チェックは実装後に結果を記録してから付ける。

## 工程と担当範囲

| 工程 | 遊んで確かめられる到達点 | 前提 | 対応する要件 |
|---|---|---|---|
| T01 | 一本の道を選んで出発し、表示した出目から再開できる | なし | R01・R05・R48 |
| T02 | 選んだ道に100マスが並び、未訪問の宿場と城で正しく止まる | T01 | R03〜R10・R14・R22・R34・R40〜R42 |
| T03 | 着地した出来事を選んで解き、買い物・休憩・宝箱の受け取りができる | T01・T02 | R09・R11〜R20 |
| T04 | 転職し、仲間・剣と防具・呪文を選び、レベルが上がる | T03 | R31〜R40・C02 |
| T05 | 敵の予告を読み、任意の強敵と魔王に挑み、勝利の品を受け取れる | T02〜T04 | R15・R16・R21〜R30・R37 |
| T06 | 11画面で操作し、結果を読んで聞ける。演出の長さと音量を変えられる | T01から着手、最終確認はT05後 | R41〜R47・S01〜S11・C01・C03 |
| T07 | 4ルートを最後まで遊べ、結果・図鑑を残して新しい旅に出られる | T01〜T06 | R02・R29・R48〜R50・C02・C04・C05 |
| T08 | 正式URLで遊ぶ15言語の公開版・X共有・配信の準備ができる | T07、正式URLの決定 | C01・C05、公開条件 |
| T09 | 実験場への登録後、同じ日・ルート・ルール版・コンテンツ版の成績を比べられる | T08、登録先・日程の決定 | R49・C05、ランキング条件 |

スマホのブラウザーで遊ぶ静的なページ（HTML・CSS・JavaScript）を想定する。最初の読み込み後、試遊版の進行と保存は端末内で完結させる。以下の `src/`・`tests/` などは、これから作るファイルの候補。実装開始時に既存の構成を確認し、先行する作業があれば、その配置に合わせる。

| 作成予定のファイル | 責任と受け渡し |
|---|---|
| `src/content.js`・`src/events/` | 正本を読み、識別子ごとに画面に出す文、受け付ける操作、成立条件と結果を結ぶ。不明な識別子や未定義の分岐があれば検査で止める。 |
| `src/game.js`・`src/board.js` | 状態と一つの操作を受け、新しい状態と表示する出来事を返す。配置・移動・入出金・品物の受け取りを、画面・時計・音に依存せず再現する。 |
| `src/party.js`・`src/battle.js` | 成長、職・仲間・装備・道具、戦場ごとの仕掛け、敵の予告、戦闘と戦利品を処理する。 |
| `src/save.js` | 端末内で複数の更新を一度に保存する仕組み（IndexedDB）を使う。冒険ID・期待する更新番号・操作IDを照合し、全体が保存できて初めて成功を返す。 |
| `index.html`・`src/main.js`・`src/screens.js`・`src/style.css`・`src/audio.js` | 入力を一つの操作にまとめ、確定した結果だけを文字・絵・音で表す。試着、下見、取消は入手・支出と区別する。 |
| `tests/*.test.mjs`・`tests/browser/`・`src/locales/` | 同じルールを決めた入力で検査し、ブラウザーでも指の操作・中断・再開を確認する。翻訳は同一の文言識別子に対応させる。 |

ブラウザーとテストで同じ計算を使う。最初の実装変更で必要なら `package.json` に `"type": "module"` を設定する。任意の所持品や戦闘途中を作る検査用の入口は、プレイ画面には置かない。

## 実装と検証の手順

### T01　出発・入力・再開を先に通す

- [ ] 1番「四つ辻の旅立ち門」に旅人・レベル1・支度金200G。旅立ちの剣（SW01）、旅人の服（AR01）、薬草（HE01）と旅のコンパス（BD01）各1個で始める。金貨の商人道（M）、職人の鍛冶道（F）、魔獣の討伐道（B）、灯火の巡礼道（H）の特徴と配分を比べて一本を確定する。冒険開始時にルートと配置を一緒に保存し、途中の選択・区間移動・復帰で変えない。T01では正本の4枚の配置例を検査用に使い、T02で実際に生成した配置へ差し替えて同じ保存・再開を確かめる。
- [ ] 「振る前 → 素の出目を表示 → 移動確定 → 着地の出来事 → 次の手」を分ける。振った時に等確率の1〜6の素の目と手数＋1を一度だけ保存する。道具を試す、施設を使う、戦闘ラウンドを進める、再戦する、では手数を増やさない。乱数の元・抽選位置とすでに選ばれた内容を保存し、再描画で振り直さない。
- [ ] 冒険ID、保存形式・ルール・内容の版、更新番号、ルート・配置、現在地・最遠到達、素の目・確定出目・前手の出目、使用中の道具と残り条件、体力・魔力・経験値・所持品を保存する。出来事の途中、宿の在庫と使用済み印、箱の候補、戦闘開始時の控え・予告・本体、再戦権、勝利と受け取り待ちも段階ごとに保持する。設定・発見・自己ベストは次の冒険へ引き継ぐ。
- [ ] `tests/save.test.mjs` とブラウザーで、連打・二つのタブ・容量不足・保存拒否・再読込を試す。保存の途中で失敗したら以前の状態を守り、成功音なしで再試行できる。同じ版からの二操作は片方だけ採用し、古い操作を新しい版で再送しない。「はじめから」は進行中の地点を示して確認し、切替後に旧タブから旧冒険を復活させない。旧形式の移行は成功時だけ置き換え、破損・未知の版は自動初期化しない。

### T02　各ルートの盤面を作り、宿場と城で止める

- [ ] 正本の `counts`・`bands`・`routes`・`mapPolicy` と実データを突き合わせる。固定は1番・100番だけ。20マスずつの5区間 × 4ルート＝20組で、各組50件、各ルート250件、候補は合計1,000件。固定2件は別に数える。各組を金貨・装備・戦闘・道具・回復・宿場・選択・罠に分け、候補数は `candidatesPerBand`、実配置は選んだ道の `slotsInTwenty` に従う。
- [ ] 2〜20／21〜40／41〜60／61〜80／81〜99番に、それぞれ19／20／20／20／19件を重複なく置く。短い両端だけ20件用の配分から罠を1件減らす。各区間の抽選位置の2〜7番目のどこかに宿場を1か所、選ばれた装備・道具マスのどこか1か所には宝箱を添える。宝箱はマスを増やさない。各箱の候補3点・補充用消耗品と位置まで冒険開始時に保存する。
- [ ] 現在地より先にある最初の未訪問の宿場か100番を上限に進み、余りは捨てる。区間の境目・強敵には通過だけで止まらず、通常の出来事は着地したときだけ起こす。実際に初めて進んだ1マスにつき経験値1。最遠到達・確定出目・実移動距離を別々に記録する。地図は次の6マス（終点付近では100まで）と宿場・城を読めるようにする。
- [ ] 出目を変える道具は1手1個。BD01は出目を見て±1、1〜6の範囲内だけ、取消は消費しない。BD02・BD12・BD31は振る前、BD11・BD21・BD22・BD41・BD42は出た後の固有条件を実装する。前払いして素の目が変化しなくても消費する品、前手の目が必要な品、調整前後の停止先が同じ場合にしか使えない品を区別する。BD43は12マス先までの着地を通常2回の36通り（初手での到着も含む）から示すだけ。BD50の正解も回復の予約であり、手数・行先を変えない。
- [ ] `tests/board.test.mjs` で4枚の `exampleBoards` を読み、別に新規生成する盤面でも固定位置・件数・種類・宿と箱・経路・重複なしを調べる。例の商人道では7番から3でも4でも8番の宿に止まり、歩行経験値は1、確定出目は別。宿を出た次の手で再停止せず、宿を越さない範囲では区間をまたげる。98番から5なら100番だが未討伐。各ルートで全位置・全出目・該当する全調整道具の合法／不許可・取消を調べる。先読みで移動・戦闘・報酬は起こらない。

### T03　各マスの操作、宿場、宝箱、道具袋をつなぐ

1,000件の `scene`・`action`・`result` は読者向けの日本語で、実行命令ではない。各識別子に、どんな入力を許すか、どの条件でどの結果になるかを記した処理表を作る。表には選択肢の識別子、対象・正解・手順、数値の境目、費用・効果、適用時期・期限・回数、失敗・見送り・再開先を型付きの値として持たせる。識別子の参照一覧（`refs`）は、掲載された品を全部渡す指示ではない。文章から数字や品名を拾って自動付与しない。

- [ ] 検査用に8種類から代表場面を一つずつ通す。次に道×区間の50件ずつを入れ、原文と処理・期待結果を照合する。戦闘中の条件はT05、完成判定はT07で扱う。例えば M1-42 は給金なら150G、昼食なら体力＋7・入金0。B2-02 はどちらの完了でも240Gだが、綱で引く方だけ体力を2使い（最低1）、次の通常敵の名前が分かる。B2-48 の棒は100Gの**支出**、岸石なら目1〜3で体力2、4〜6で4を使い最低1、札なら無傷。入力・分岐・費用を個別に試す。
- [ ] 直接の支給額 `directGold` は選ぶ前の表示に使い、`goldAward` の指定行動が完了した時（`completedAction`）、または指定結果になった時（`specifiedOutcome`）だけ、100〜1,000Gを同じ冒険・同じマスで一度入金する。条件外は0。戦闘の勝利金・買い物・通行料は別の入出金にする。支払えない選択では残高を変えず、見送りか無料の手段を示す。正本に直接支給の指定がある185件（金貨150件・選択35件）を含め、選択前・成立後・別の結果・再読込を照合する。
- [ ] 各宿で無料休憩を1回、現在の体力・魔力に各最大値の半分（切り上げ）を足し、上限で止める。休憩・売店・転職・酒場を任意の順で利用できるようにし、宿固有の一度限りのサービスは共通休憩と別に記録する。定番は薬草・旅のコンパス、地方枠は2品。第2／3／4区間はSP02／SP03／SP04、第5区間はSW50「百歩の夜明けの剣」（3,000G）を地方枠の一つに保証する。他の商品の単価はすべて3,000G未満。次の宿の棚はBD09で先読みしても入店時と一致させる。BD40で明示的に取り寄せられるのは地方枠の消耗品から同じ区間・分類の別の消耗品へ、1宿1回だけ。確定後の品と使用済み印を保存し、定番・保証品や再入店による引き直しに使えないようにする。
- [ ] 宝箱は元のマスを解決してから開く。通常は保存した先頭2候補、旅芸人は3候補を示し、1品を選ぶ。対象はその区間の剣・防具・3分類の道具と、第2〜4区間の対応呪文書。所持済み装備・習得済み呪文書は同区間の保存済み補充用消耗品で置き換え、表示中の候補を重複させない。元のマスの処理済み印・提示した箱の内容・箱の受け取り済み印を区別し、中断で報酬を増やさない。
- [ ] `tests/events.test.mjs`・`tests/facilities.test.mjs` で袋の合計6個を確認する。拾得・箱・戦利品で満杯なら交換か辞退、購入は空きを作ってから。装備取得・習得は袋の外。確認中は元の品・残金・候補を守り、交換／購入時だけ手放す品・数量・支払い・取得を一度に反映する。残高2,999G／3,000G、体力1の罠、奇数上限の休憩、候補の補充、最後の品の見送り、各確定直前／直後の再開を試す。

### T04　成長・転職・仲間・装備を実際の効果に結ぶ

- [ ] `levelTable` の全20段階を読み、全職・全ルートで同じ経験値と成長を適用する。レベル1の装備補正前は最大体力40・最大魔力10・攻撃6・防御4。初めて進んだ距離に、戦闘勝利と出来事に明記された経験値を足す。1レベルごとに4能力を各＋2、現在の体力・魔力は維持する。余りを次へ繰り越し、一度に複数段階上がれる。累計経験値11／12、27／28での境目、912でレベル20（補正前78・48・44・42）、それ以後に能力が増えないことを試す。
- [ ] 最初の宿場で全職共通の「火花」（SP01）を無料で覚え、任意に転職する。戦士は防御後の一撃、魔法使いは攻撃呪文の節約、旅芸人は宝箱の3候補。転職で現在の職の力だけを切り替え、レベル・装備・習得は保つ。4呪文の準備枠は2、呪文書は消耗品150種に数えない。酒場では仲間4人から同行中を除く二人を一度提示し、1宿場で無料加入は1人。同行2人まで、体力は一行で共有。支援の条件、満員での交代・取消と再開を確かめる。
- [ ] 剣50種・防具50種を各1枠、計2枠とし、全職で使える。装備の基本値と個別効果を分け、発動時期・対象・回数・失効条件まで登録する。付け替えは振る前・宿場・城門前・再戦準備に限る。AR07「一歩のブローチ付きマント」は防具枠で、確定出目1なら移動確定時に体力＋2（上限まで）。実移動1でも目が4なら発動せず、出目を見た後には着替えられない。
- [ ] 消耗品は戦闘用AT・回復用HE・すごろく用BDを各50種とする。**使用場所は分類名では決めない。** 全150品それぞれに `timing`・`effect`・`limit` に対応する入力・条件・対象・数値・期限・消費時点を持たせる。例としてAT02の札は戦闘か罠の確定前、HE01は戦闘・宿場・城門前、HE09は宿の無料休憩確定時、BD49は100番の城門前だけ。戦闘中に使う品は勇者の1行動。戦闘をまたぐ予約は記載どおりの移動回数・発動回数を保持し、同じ品の待機効果は重ねない。
- [ ] `tests/party.test.mjs`・`tests/items.test.mjs` で、装備全100種の発動／不発、消耗品全150種の使える場面・使えない場面、境界値と消費を照合する。対象なし・魔力不足・使用不可・取消で余計に消費せず、変化がなくても先払いする品は個別の例外を守る。剣・防具・各分類の道具は1区間につき各10種。店・箱・イベント・戦利品の入手経路を対応づけ、特定の冒険に全種が並ぶことは条件にしない。

### T05　通常戦・任意の強敵・魔王戦と再戦を通す

- [ ] 通常敵8種（EN01〜EN08）は `bands`・`battleRewards` の出現区間と予告に合わせる。主分類が戦闘の185件のほか、B2-43／B3-43／B4-43／B5-43は選択の片方から通常戦へ入る。通常戦は敵の行動前に確実に逃げられる。任意の強敵は石門番（MB01・第3区間）・鉄甲虫（MB02・第4区間）・霧狼（MB03・第5区間）。現データで候補があるのは鍛冶道と討伐道の該当区間各1件。採用・着地時でも挑戦前なら見送れ、挑戦後は逃走不可。これらの敵に勝つことを区間通過の条件にしない。魔王（DK01）は全ルート共通の100番で門前準備後に挑み、逃走できない。
- [ ] 各戦場の入力と仕掛けを、敵本来の予告に重ねる。B3-26では表示した目と合計7になる答えなら敵の初期体力を5減らす（最低1）。誤答では勇者の魔力を2減らす（最低0）。勇者が行動し、敵が生きていれば予告どおりに動く。被弾で発動する反撃やその手の継続ダメージの条件を適用し、一行が体力0なら敗北、一行が生きていて敵が0なら勝利を一度だけ確定する。双方が生きている場合だけ回復支援から次の予告に進む。魔力不足・対象未選択で消費も敵の手も進めない。確定出目1〜3は最初の正の被害を軽くし、4〜6は勇者の通常攻撃・攻撃呪文・火薬玉（AT01）のうち、最初に直接ダメージを与える一撃を強くする。防御→盾役→小さい目の効果→札の順に軽減し、すでに被害0なら使い切りの印は残す。回復・防御・予告を見る操作でも加勢を使わず、持ち込む戦闘がなければ手番終了で消す。大きい目でAT05を使い、次に通常攻撃を当てる検査では、AT05の4ダメージには加勢せず、次の通常攻撃で一度だけ発動する。装備の追加分は命中・本体・場面の仕掛けを解決した後の対象へ、1回指定なら連続攻撃の最初の該当打だけに適用する。
