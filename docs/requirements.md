# 100マス勇者　要件仕様書

2026年11月7日採用。原案の50項目と追加の確認5件は、すべて推奨案を採用する。採用した内容を **R01〜R50**、初版と公開に関する決定を **C01〜C05**、画面を **S01〜S11** として参照できる。[実装計画書](./implementation-plan.md)

## ゲームの目的と一周の流れ

「100マス勇者」は、一人で勇者と仲間を率い、100マス目の魔王城で魔王を倒すすごろく。次の6マスを見て、危険を引き受けて金貨を稼ぐか、道具を使って宝箱を狙うかを選ぶ。選んだ職、仲間、装備を魔王戦で生かす。

0番の出発地は100マスの外に置く。勇者は「旅人」として剣・服・薬草1個・旅のコンパス1個を持って始める。サイコロを振り、必要なら出目を調整し、移動先を確定する。着地した出来事を解決して次の一手へ進む。100への到着、魔王との交戦、魔王討伐は別の状態として記録する。

| 地方 | 必ず寄る宿場 | 止まったときに選ぶ分かれ道 | 区間の終わり |
|---|---|---|---|
| 草原 1〜25 | 10・火花を習得 | 18 | 25・石門番 |
| 鉱山 26〜50 | 35 | 43 | 50・鉄甲虫 |
| 霧の森 51〜75 | 60 | 68 | 75・霧狼 |
| 城下 76〜100 | 85 | 93 | 100・城門で準備して魔王に挑む |

## 一手・戦闘・再戦の境界

**出目と移動。** 振った瞬間に素の出目と手数を記録する。コンパスの候補を見る間は消費せず、移動確定の1回で調整後の目・消費・実到着位置を確定する。現在地より先にある最初の強制停止地点と100を上限とし、歩いた距離だけ経験値に加える。振った回数に戦闘ラウンド・施設・再戦・演出時間は含めない。41で3が出れば44、コンパスで4に変えれば45に着く。

**戦闘。** 予告に対して勇者が行動し、倒したらその場で勝利する。敵が生きていれば予告どおり行動する。防御・盾役・札などの軽減を被弾前に適用し、残った体力を確定する。体力0なら敗北、生存したときだけ回復役の条件を調べる。大技を防ぐ手段と通常攻撃は魔力0でも使える。霧狼では分身を含む対象を選べる。魔王の残り体力が半分以下に達したときの王冠演出は1戦1回。非致死ならその手の予告を守り、次の予告から後半へ移る。倒した一撃では勝利を優先する。

**再戦。** 戦闘開始時の装備・個数・魔力・敵・出目効果を記録する。再戦の権利の消費と戦闘開始時点の復元は同時に保存し、同じ敵に対して装備と呪文を選び直せる。体力と魔力はそれぞれ開始時の値と最大値の半分のうち高い方を使う。戦闘前に使ったコンパスや城門前の薬草は、戦闘開始時点ですでに消費済み。戦闘が始まってから使った品だけを戻す。次の敗北、または再戦の辞退で結果を出す。

**取得と消費。** 通常戦の逃走時も、すでに歩いた距離の経験値は残る。裏道の強敵にもこの規則を使い、逃げたら宝箱は出さない。宝箱・購入・加入で選び直している間は入れ替え先や所持金を先に変えない。確定時に支払い・取得・一度限りの印をまとめて反映する。装備と準備呪文を変えられるのは、振る前の盤面・宿場・城門前・再戦準備。出目が見えている間、着地した出来事の解決中（宿場・城門前を除く）、戦闘中は参照だけとする。

### 数値と運用で補った点

以下は、採用済みのルールを一貫して実装するための取り決め。価格や敵の体力などの調整値は、初版の量・勝利条件とは分けて管理する。

| 場面 | 初版でそろえる扱い |
|---|---|
| 端数と防御 | 無料休憩と再戦最低値の「半分」は切り上げて最大値まで。札は次の正の被ダメージを半分にし切り上げる。複数の軽減は防御→盾役→小さい出目の効果→札の順で、0未満にしない。効果の直前ですでに0なら使い切りの印は温存する。実際に失う量を表示する。 |
| お守り・出目効果 | 一歩のブローチは移動確定時に一度だけ適用。小さい出目は最初の正の被ダメージ、大きい出目は、勇者の通常攻撃・攻撃呪文・火薬玉のうち、最初に直接ダメージを与える一撃に一度だけ発動する。持ち込む戦闘がなければ手番終了で消える。 |
| 道具・加入の在庫 | 消耗品は同じ品も1個ずつ数える。装備・習得呪文は種類で管理。宝箱は職に応じて異なる2品／3品を示し、既所持装備・習得済み呪文を除いて候補不足なら、同じ箱内で品が重ならないよう消耗品5種から必要数を補う。酒場は同行中を除く二人から提示する。 |
| 保存と記録 | 冒険進行を同一端末で1件保持し、図鑑・自己ベスト・設定は別に引き継ぐ。冒険が残る状態で「はじめから」を押したら、現在地を示して続きが置き換わることを確認する。保存できない場合は直前の記録を保ち、未確定の操作をやり直せる。読み込めない既存データは自動初期化せず、進行を止めて再試行を案内する。 |
| 戦績の見せ方 | 敗北・終了時にも到達地点と振った回数を表示する。100で敗北した記録より、100で討伐した記録を上に置く。同じ個人の新しい記録が劣るときは自己ベストを保持し、同順位の場合は次の人の順位を人数分進める。通常戦・関門の勝利では冒険を続ける。終局になるのは魔王討伐・再戦辞退・権利消費後の敗北のいずれか。 |
