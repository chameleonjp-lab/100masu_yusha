# 盤面情報道具の処理

`boardItem` は `id` と道具入力（`pos` または `kind`）を使う。対象はすでに生成・保存された同じ道の盤面だけであり、情報確認で配置や受取品を再抽選しない。対象なし・範囲外は操作全体を取消し、道具を消費しない。

- BD03: 先6マスかつ1〜6の今回移動で到着可能な戦闘。宿の強制停止を越さない。イベント固有初手の予告を優先。
- BD10: 同条件の通常戦へ到着予約。最初の本体通常攻撃だけ+6、別地点へ着地したら失効。
- BD13: 先6マスの回復/選択/罠を複製状態で試算。HP/MP/金貨の実増減を返す。未知の出目は1〜6別 `outcomes`、数値入力は `variants`、入れ子選択は `choices`。支払不能は理由を出す。元の保存・金貨・品・乱数位置を変更しない。着地時には改めて計算される。
- BD15: 先10マスの装備/道具から実受取命令にある品を作者順で2つまで表示。支払品は含めない。対象を通過すると印失効。
- BD24: 先の最寄り任意強敵と勝利金貨・経験値。移動も挑戦も実行しない。
- BD32: 先6マスの罠へ予約。3移動以内かつ未通過でそこへ着地した罠のHP/MP損を各ceil半減。金貨・品・道具使用の支払には適用しない。
- BD47: 今の帯の残り装備/道具/回復の選択種類をすべて表示。4回移動か帯外で失効。

`tickInfoMarks` は確定移動後・着地前だけ呼ぶ。素の出目表示、保存再読込、画面描き直しは期限を減らさない。ブラウザ表示とiPhone受入はローカル論理テストとは別に確認する。
