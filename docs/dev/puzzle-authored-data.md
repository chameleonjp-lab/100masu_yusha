# パズルの原文と実装用補完データ

原本は `data/adventure-content.json`。元のイベント ID、取得品、金額、ゲームルールは維持する。
本書の「補完」は原文から確定した数値・図ではなく、計画書の仕掛け操作と補助道具を実行可能にするため新作した実装用問題データ。

## 原文から確定できる内容

- M1-01: ヒナギクの絵→白い花、スミレの絵→紫の花。2組の対応入力。成功100G、誤答0G。
- M1-02: 袋を横にする→穴に布を当てる→荷ひもで押さえる。3手の順番入力。成功160G、誤答0G。
- F1-15: 二枚を重ねると留め具が通る。別々の目分量は失敗。AR03は成功時だけ。
- F1-19: 青糸がほどき口。赤糸は詰め物。AR08は青糸だけ。
- 得失だけの選択（例 F1-13の剣/防具選択）はパズルにしない。

## 実装用補完データ（新作・原文確定ではない）

### M3-08 計り升の目盛り

原文は「一人分ずつ大びんに移し、油の高さに細い横線を引く」。具体的な杯数、容量単位、選択範囲は未定義だった。
見本を **升4杯**、1杯=1目盛り、回答範囲0〜8と補完する。回答4が正答。見本の杯数を画面に表示し、隠れた正解の当てずっぽうにしない。報酬は原文の460G、誤答0Gを維持。
BD26は異なる2値の見本との差だけを比較し、正解や数値差を返さない。

### M5-15 窓の明かり

原文は見本と違う窓が一つ。具体的な窓配置は未定義だった。
実装用に3×3の窓を並べた簡略表示を新作する。文字「宿」の厳密な字形の再現ではなく、見本と明かりを照合する仕掛け用の配置。

見本（1=点灯）:
```
1 1 1
0 1 0
1 1 1
```
現在:
```
1 0 1
0 1 0
1 1 1
```

差分は1行2列 `r0c1` のみ。9窓から直す窓を選ぶ。報酬は原文の860G、誤答0Gを維持。正答・差分リストは表示せず、公開する見本/現在の図だけで比較できる。
BD44は行→列順の最初の差分を一つ示す。BD05は3候補以上から確実な誤答を一つだけ除く。

## 共通保証

`puzzles.js` は補助中に報酬・損失・手数を変更しない。各補助は1問1回。BD39は最初の誤答確定前だけ保留し、再選択か元の結果確定を選べる。次の回答で解決し二重報酬を出さない。
元の単一完了ボタンは監査可能な旧optionsとして残すが、型付き仕掛けでは本番回答 `answerPuzzle` を通らなければ報酬を得られない。
